# Skill: Voice Agent Builder

> Step-by-step guide for creating ServiceNow AI Voice Agents with telephony integration.

---

## Purpose

This skill guides you through creating AI Voice Agents in ServiceNow Zurich — phone-based AI agents that deliver natural, conversational support replacing rigid menu trees.

## When to Use

Use this skill when you need to:
- Create a voice assistant and voice agents
- Configure telephony provider integration (Twilio, Genesys)
- Set up voice authentication
- Configure fallback and safeguard options

## Prerequisites

1. ServiceNow Zurich instance
2. `sn_aia.admin` role
3. `sn_aia.enable_voice_agent_setup` property set to `true`
4. Now Assist for Platform plugin (`sn_genai_platform`) installed
5. Voice agent collection installed:
   - ITSM: `sn_itsm_voice_aia`
   - HR: `sn_hr_voice_aia`
6. Telephony provider account (Twilio or Genesys Cloud)

---

## Instructions

### Step 1: Create a Voice Assistant

A Voice Assistant is the virtual help desk that hosts multiple AI voice agents.

Navigation: All > Conversational Interfaces > Assistant Designer > Assistants > Create assistant > Voice-only

| Field | Description |
|-------|-------------|
| Name | Name of the voice assistant (e.g., "IT Service Desk") |
| Description | Business outcome summary |
| Tags | For analytics tracking (do not affect functionality) |

**Voice Personality:** Select language (English, German, Spanish, Japanese), voice persona, and customize the welcome message. All agents on one assistant share the same voice.

### Step 2: Configure Communication Channel

At least one channel required to activate the assistant.

#### Telephony Provider (Twilio)
1. Get Account SID and Auth Token from Twilio console
2. Navigate to Assistant Designer > Assistants > Edit
3. Select Twilio as provider, enter Auth Token
4. Copy autogenerated webhook URL
5. In Twilio console: set this URL as Webhook URL for your purchased phone number

#### Telephony Provider (Genesys Cloud)
1. In Genesys: Menu > IT and Integrations > Integrations
2. Create Audio Connector integration
3. Add WSS URL: `wss://aivoiceservice-prod-main-prod.sncapps.service-now.com/genesys/stream/connect`
4. Add API Key and Client Secret from ServiceNow
5. In Genesys Architect: Create inbound call flow with Connector ID
6. Configure call routing and assign phone number

**Important:** Query parameters in Genesys Connector ID must be in correct order or validation fails.

#### Mobile App
- Voice launcher function in ServiceNow mobile app
- Fallback: record producer ticket creation only

### Step 3: Configure Authentication

Only applies to telephony channel.

**Identification Methods:**
- Phone number (auto-match caller ID)
- Fallback method if primary fails

**Authentication Methods:**
| Method | Description |
|--------|-------------|
| Knowledge-based (KBA) | Numeric data only (DOB, SSN, employee ID). Source table must reference `sys_user` |
| Okta Verify | Push notification |
| SMS verification | Code sent via SMS |
| Authenticator app | TOTP code |
| Soft PIN | PIN-based |

**MFA:** Required by default. Set `glide.voice.authenticate.mfa_mandatory = false` for single-factor.

**Security properties:**
- `voice_max_retries`: Max authentication retries before lockout (default: 3)
- `voice_minutes_account_is_locked`: Lockout duration in minutes (default: 1440)

### Step 4: Configure Safeguards

**Fallback options:**
- Telephony: Connect to live agent OR record producer ticket creation
- Mobile: Record producer ticket creation only
- Option: "Capture details before live agent handoff"

**Time limits:**
- Max call duration (triggers fallback when reached)
- Inactivity reprompt duration (up to 60 seconds; disconnects if no response after reprompt)

### Step 5: Create AI Voice Agent

Navigation: All > AI Agent Studio > Create and manage > AI agents > Add > Voice

| Field | Description |
|-------|-------------|
| AI agent name | Name based on outcome (e.g., "Incident Manager") |
| AI agent description | Summary of autonomous activities |
| AI Agent role | Capabilities and responsibilities |
| List of steps | Step-by-step instructions sent to LLM |

**Available tool types for voice:**
- File upload (PDF, DOCX, TXT)
- Flow action
- Knowledge Graph
- MCP server tool
- Record operation
- Script
- Search retrieval (use dedicated search profile to reduce latency)
- Subflow

**Important:** Tool data input/output type MUST be string for optimal voice experience.

### Step 6: Activate

Activation requirements:
- [ ] At least one communication channel selected
- [ ] At least one AI agent associated
- [ ] If telephony: authentication set up + fallback configured
- [ ] If mobile: fallback configured with record producer

### Step 7: Monitor

Dashboard: All > Assistant Designer > Analytics > Voice tab

Key metrics:
- Total voice conversations
- Calls completed without live agent (Agent chat=false)
- Conversations transferred to live agent
- Number of tickets created
- Inferred CSAT (1-5 scale)
- Average conversation duration

## Roles

| Role | Description |
|------|-------------|
| `sn_voice_aia.admin` | Voice agent configuration access |
| `sn_voice_aia.guest` | Use AI voice agents without authentication |
| `sn_voice_aia.integration` | Access to integrations (e.g., Oracle) |

## Voice-Specific Gotchas

- Keep record producer fields simple and short for voice fallback
- PII data is redacted from transcripts before storage
- Create a dedicated search profile for voice agents to reduce latency
- Privacy: comply with anti-wiretapping, recording consent laws
- Genesys: host instance in same region as Genesys Cloud for latency
- All agents on one assistant share the same voice persona
