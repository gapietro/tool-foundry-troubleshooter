ServiceNow Platform Assistant

Build an AI-powered troubleshooting assistant that runs entirely within ServiceNow, routing all LLM calls through GenAI Controller via NASK skills. Server-side ReAct agentic loop exposed via Scripted REST API, with a React chat UI. All queries use GlideRecordSecure. Destructive ops require user confirmation.

PaToolQueryTable
Table query tool
  • Createsrc/instance/script-includes/tools/PaToolQueryTable.js

Executes GlideRecordSecure queries. Accepts: table (required), query (encoded query string), fields (comma-separated, default: sys_id,number,short_description,state), limit (default 20, max 100).

Validates table exists via GlideTableDescriptor.isValid(). Orders by sys_created_on desc. Returns {success, data: {table, query, count, records[]}}.

PaSessionManager
Conversation state
  • Createsrc/instance/script-includes/PaSessionManager.js

Manages u_pa_session records:

  • getOrCreateSession(sessionId?) — loads existing or creates new (GUID)
  • addMessage(sessionId, role, content, toolExecutions?) — appends to u_messages JSON
  • setPendingAction(sessionId, action) — for destructive op confirmation
  • consumePendingAction(sessionId) — retrieves and clears pending action
  • buildConversationPrompt(sessionId) — assembles context + messages for LLM
  • closeSession(sessionId) — sets status to closed

Context summarization: after 10 messages, calls PaLlmProxy.summarize(), stores summary in u_context, keeps only last 4 messages. Session expiry: 30 min inactivity check on load.

PaAgentLoop
Core ReAct agentic loop
  • Createsrc/instance/script-includes/PaAgentLoop.js
  • Testsrc/instance/script-includes/__tests__/PaAgentLoop.test.js

The central orchestrator. run(params) implements:

  1. Get/create session via PaSessionManager
  2. If confirmationResponse provided → handle confirmation flow
  3. Otherwise: add user message, enter ReAct loop (max 8 iterations)
  4. Each iteration: build prompt → PaLlmProxy.reason() → parse response
  5. TOOL_CALL + destructive → store pending action, return confirmation_required
  6. TOOL_CALL + safe → execute via PaToolRegistry, feed result back
  7. ANSWER → save to session, return {status: 'success', response, toolExecutions}
  8. Max iterations → return partial results

Helper: _describeAction(toolName, args) — human-readable description for confirmation dialog.
